# 浏览器仪表盘

网关直接托管仪表盘：<http://127.0.0.1:8788>（纯原生单页，无构建）。所有操作即改即生效并持久化到 keys.json。

## 八个视图

| 视图 | 作用 |
|---|---|
| **总览** | 池子状态卡（Key 数/状态分布/**优先中**/请求数/总 token）+ **双分区**：上区「优先通道 · 中转站」（翠绿识别色，含隔离红卡与「重新激活」）、下区「默认通道 · OpenCode Go」（琥珀，现状）；**使用中卡片挂转圈彗星流光**（Go 卡琥珀 / 中转站卡翠绿 = 在途请求或近 10 分钟有流量）；同池告警横幅 |
| **Key 管理** | 录入 / 改名 / 替换 / 停用 / 启用 / 删除；每把 Key 的三窗口用量条与请求统计；右上角「立即刷新」批量重查全部 Key 额度 |
| **隔离区** | Go Key 的隔离（月限/手动）与失效；「一键恢复」全部重查、月窗已恢复的自动放回池。**中转站的隔离不在此**（在「中转站」视图） |
| **会话绑定** | 会话 → Key 绑定表（会话 id、请求数、最近活跃）；排查「这个会话走的哪把 Key」 |
| **中转站** | 中转站优先通道配置（列表 / 添加编辑表单 / 优先级与自动重排 / 半填半选模型输入 / 测试连接）+ **隔离小节**（额度耗尽/连败/401/手动，仅可手动「重新激活」探活复活）+ 「启用优先通道」总开关 |
| **备用通道** | 备用上游配置（含「测试连接」）+ 启用开关；费用卡（当前余额 / 本周期花费 / 24h/7d/14d/30d 窗口、「立刻计算」）；结算记录与 token 明细（`billingMode=none` 时不显示费用区） |
| **事件日志** | 全部调度事件（类型筛选、中文解释悬停可见）；排障第一入口 |
| **设置** | 运行时配置（轮询间隔/并发/粘性/空回复重试/**中转站响应头超时**/本地 token），表单即当前生效配置；「Agent 对接指引」可复制的委派提示词 |

## 读数口径

- **实时推送（SSE）**：顶栏「实时」指示亮绿 = 事件/流量经 `/api/stream` 即时到达——**使用中光效秒级点亮**（不等刷新周期）、事件日志即时出新条目；变灰 = 推送断开（浏览器自动重连）。拉取轮询（30s/1min/5min）保留为兜底对账，不再决定新鲜度。
- **用量条三档分色**：绿 < 90% → 金 ≥ 90% → 红 ≥ 100%（红 = 已限流，条拉满）。三窗口（5h 滚动 / 周 / 月）各一条。
- **token 单位**：百万（M）与亿两档中文显示。
- **缓存命中**：有缓存收益、未因 Key 切换丢缓存的**请求次数**（不是缓存 token 量）。
- **总 token**：Go 池各 Key usage 累计 + 备用通道 token 明细之和。

## 事件类型速查（悬停标签有中文解释）

| 类型 | 含义 |
|---|---|
| `bind` / `migrate` | 会话首次绑定 / 迁移到另一把 Key（原 Key 不可用） |
| `enroll` / `edit` / `delete` | Key 录入校验通过 / 编辑 / 删除 |
| `cooldown` / `recover` | Key 进入冷却（窗口打满）/ 恢复可用（窗口重置） |
| `rate-limited` | 上游返回 429 限流 |
| `failover` | 请求失败自动换 Key 重试 |
| `quarantine` / `reactivate` | Key 进隔离区 / 手动重新激活 |
| `invalid` | Key 认证失效（401），需删除重录 |
| `exhausted` | 所有 Key 都失败，请求被如实拒绝 |
| `cache-hit` | 该请求命中上游缓存 |
| `same-workspace-alert` | 多把 Key 共享同一额度池（轮换无效） |
| `upstream-5xx` | 上游服务端错误 |
| `empty-stream` | 上游空回复被掐断，触发客户端自动重试 |
| `config` / `refresh` | 配置变更 / 批量刷新额度 |
| `fallback` | Go 无可用 Key，请求转备用通道 |
| `fallback:start` / `fallback:end` | 备用周期开始 / 结束（切回 Go 并结算花费） |
| `fallback:fail` / `fallback-test` | 备用通道请求失败 / 测试连接 |
| `relay-fail` / `relay-isolate` | 中转站前置请求失败（连败计数） / 被隔离（额度/连败/401/手动） |
| `relay-recover` / `relay-test` / `relay-edit` | 中转站手动复活成功 / 测试连接 / 配置变更 |

## Agent 对接指引（设置页）

一段可直接复制发给你的 AI 助手的**委派提示词**：助手读完本仓库 README 与文档后，替你把客户端 baseURL 指向网关（备份配置、保留直连逃生门、改前征求同意、完成后汇报）。内容由网关运行时生成（`GET /api/guide`），自动带上你这台机器的安装目录与端口——别的机器部署时显示的是它自己的路径。
